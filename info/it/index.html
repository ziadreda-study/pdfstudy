Cos'è questo sito?

Mothakertak è uno strumento gratuito che funziona direttamente nel browser, senza download e senza account. Apre file PDF, PowerPoint (pptx), Word (docx), file di testo e immagini, e ti dà strumenti per studiare: un evidenziatore per l'importante, una penna per disegnare e scarabocchiare, testo sulla pagina, una gomma e la traduzione in arabo. Quando hai finito, salvi una nuova copia del file con tutte le tue modifiche.

La cosa più importante: il tuo file non lascia mai il tuo dispositivo. Tutto avviene nel tuo browser, quindi i tuoi file di studio restano privati.

Per chi è?

Per qualsiasi studente che studia con file digitali: lezioni universitarie, riassunti, libri in PDF o slide dei professori. Invece di stampare carta o saltare tra programmi, tutto ciò che serve a uno studente è in una sola pagina.
